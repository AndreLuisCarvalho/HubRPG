# HubRPG

Painel do mestre de RPG: campanhas, fichas, NPCs, monstros e livro de regras para consulta.
Hoje com o sistema **Ordem Paranormal**.

## Rodar no PC

```bash
cd backend && npm install && npm run dev     # API em http://localhost:4000
```

```bash
cd frontend && npm install && npm run dev    # site em http://localhost:5173
```
